# 인천에프원모터스 / 원모터스 인천점 홈페이지

> 따로 운영하는 두 정비소의 홈페이지입니다. 서로 링크로 연결되어 있습니다.

| 페이지 | 상호 | 전문 분야 |
|---|---|---|
| `index.html` | **인천에프원모터스** | 자동차 고장진단 · 커먼레일/인젝터 · DPF |
| `onemotors-incheon.html` | **원모터스 인천점** | 수입차 정비 · 엔진보링 |

두 사이트는 디자인(`assets/`)을 공유하므로, 색상이나 글꼴을 바꾸면 양쪽에 함께 적용됩니다.
별도 프로그램 설치 없이 동작하는 **정적 웹사이트**(HTML/CSS/JS)로 만들었습니다.

---

## 📁 파일 구조

```
f1-wonmotors/
├─ index.html                ← 인천에프원모터스 (글자 수정은 대부분 여기서)
├─ onemotors-incheon.html    ← 원모터스 인천점
├─ assets/
│   ├─ css/style.css       ← 디자인(색상·글씨 크기 등)
│   ├─ js/main.js          ← 메뉴 열고 닫기 등 동작
│   └─ img/                ← 사진을 여기에 넣으세요
├─ 준비물-체크리스트.md     ← 준비하실 내용 목록
└─ README.md               ← 지금 이 파일
```

## 👀 홈페이지 미리 보기

`index.html` 또는 `onemotors-incheon.html` 파일을 **더블클릭**하면 브라우저에서 바로 열립니다.
(인터넷에 올리기 전에도 이렇게 확인할 수 있습니다.)

## ✏️ 직접 수정하는 법

`index.html`을 메모장이나 편집기로 열면, 바꿔야 할 자리마다 이런 표시가 있습니다.

```html
<!-- ▼ 전화번호를 실제 번호로 바꿔주세요 -->
```

### 꼭 바꿔야 하는 것

**⚠️ 두 페이지 모두 각각 수정해야 합니다.**

| 항목 | 현재 값 | 찾는 법 |
|---|---|---|
| 전화번호 | `000-0000-0000` | 페이지마다 링크 6곳 + 화면표시 5곳 |
| 주소 | `인천광역시 ○○구 ○○로 000` | 페이지마다 3곳 |
| 영업시간 | `평일 09:00 – 19:00` | 2곳 |
| 사업자등록번호 | `000-00-00000` | 1곳 |
| 카카오톡 링크 | `href="#"` (카카오톡 상담 버튼) | 1곳 |
| 지도 | "지도 자리" 안내 박스 | 1곳 |
| 로고 | CSS로 그린 임시 뱃지 | F-1: `assets/img/logo.png` / 원모터스: `assets/img/logo-one.png` |
| 유튜브 영상 링크 | 전부 채널 주소 | 영상 카드 6개 |

> 💡 **더 쉬운 방법**: 위 내용을 Claude에게 그냥 말로 알려주시면 제가 한 번에 다 바꿔 드립니다.

### 지도 넣는 법

1. 네이버 지도에서 가게를 검색
2. `공유` → `지도 퍼가기` 클릭
3. 나오는 코드를 복사
4. `index.html`에서 `<div class="map-placeholder">` ~ `</div>` 부분을 지우고 그 자리에 붙여넣기

### 사진 넣는 법

1. 사진 파일을 `assets/img/` 폴더에 넣기
2. Claude에게 "작업장 사진 넣어줘"라고 말씀하시면 배치해 드립니다

## 🌐 인터넷에 공개하는 법 (무료)

가장 쉬운 순서입니다.

1. **GitHub Pages** (무료, 이 저장소 그대로 사용)
   - 주소는 `.../f1-wonmotors/` (인천에프원모터스), `.../f1-wonmotors/onemotors-incheon.html` (원모터스 인천점)
   - GitHub 저장소 → `Settings` → `Pages`
   - Source: `Deploy from a branch`, Branch: `main` / `(root)` 선택 → Save
   - 몇 분 뒤 `https://사용자명.github.io/f1-wonmotors/` 주소로 접속됩니다.
2. **도메인 연결** (선택, 연 1~2만원)
   - 가비아·후이즈 등에서 `f1motors.co.kr` 같은 주소 구입 후 연결

## 🔎 검색 노출 (중요!)

홈페이지보다 **네이버 플레이스 등록**이 손님 유입에 더 효과적입니다. 순서대로 하세요.

1. **네이버 스마트플레이스**에 **두 곳을 각각 등록** — "인천 DPF", "인천 커먼레일", "인천 엔진보링"으로 검색되게 하는 것이 핵심입니다
2. **카카오맵** 장소 등록
3. **구글 비즈니스 프로필** 등록
4. 위 3곳 모두에 홈페이지 주소를 등록
5. **유튜브 각 영상 설명란에 홈페이지 주소 넣기** — 이미 보시는 분들이 홈페이지로 들어옵니다
