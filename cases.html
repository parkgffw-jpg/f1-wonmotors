BMW 520d 인젝터 — 교체 견적 받고 오신 경우

시동이 늦게 걸리고 매연이 심해서 다른 곳에서 보셨더니 인젝터 4개 전부 교체 견적이 나왔다고 하십니다. 저희는 먼저 리턴양을 재봅니다. 4개가 다 나간 경우는 생각보다 드뭅니다.

  1. 증상

    냉간 시동 지연, 검은 매연, 주행 중 출력 저하

  2. 진단

    리턴양 · 분사량 테스트로 어느 기통이 문제인지 특정

  3. 작업

    불량 인젝터만 탈거 후 직접 오버홀 · 재생, 테스트 장비로 재검증 후 코딩

  4. 결과

    기통별 분사량 편차 정상화, 시운전으로 증상 해소 확인

국산 디젤 커먼레일 · 인젝터

보쉬 피에조 인젝터 — 함부로 재생하면 고철 됩니다

싸게 재생했다는 인젝터를 달고 얼마 못 가 다시 오시는 분들이 있습니다. 피에조 인젝터는 재생 후 반드시 테스트 장비로 검증해야 합니다. 검증 없이 조립하면 엔진까지 망가집니다.

  1. 증상

    재생 인젝터 장착 후 얼마 지나지 않아 증상 재발

  2. 진단

    탈거 후 테스트 장비에서 분사 패턴과 리턴양을 실측

  3. 작업

    정상 공정으로 재작업, 규격값 내에 들어오는지 확인

  4. 결과

    검증 통과분만 장착, 통과 못 한 것은 솔직하게 말씀드림

국산 · 수입 디젤 DPF P2003

DPF 효율 저하(P2003) — 코드만 지우면 반드시 재발합니다

노란 경고등이 떠서 오셨는데, 이전에 다른 곳에서 코드만 지웠다고 하십니다. P2003은 "DPF 효율이 떨어졌다"는 결과 신호일 뿐입니다. 진짜 원인이 EGR이나 인젝터에 있으면 지워도 또 뜹니다.

  1. 증상

    DPF 경고등 점등, 재생 주기 짧아짐, 출력 제한

  2. 진단

    차압센서 값과 실제 차압을 함께 확인해 막힘인지 센서 이상인지 구분

  3. 작업

    상태에 따라 클리닝, 동시에 EGR · 인젝터 등 재생 불량 원인 점검

  4. 결과

    클리닝 전후 차압 비교로 개선 확인 후 학습값 초기화

국산 · 수입 디젤 DPF 비탈착 건식

DPF, 아직도 뜯고 하시나요 — 비탈착식 건식 클리닝

DPF 교체 견적이 부담돼서 오시는 분이 많습니다. 막힘이 심하지 않으면 떼지 않고 건식으로 클리닝해서 시간과 비용을 크게 줄일 수 있습니다.

  1. 증상

    재생 반복, 연비 저하, 출력 제한

  2. 진단

    막힘 정도를 먼저 확인해 비탈착으로 가능한 상태인지 판단

  3. 작업

    비탈착식 건식 DPF 클리닝 후 강제 재생

  4. 결과

    차압 정상 범위 복귀, 시운전으로 출력 회복 확인

가솔린 · 디젤 고장진단 P0300

P0300 다기통 실화 — 점화플러그가 원인이 아닐 때

실화 코드가 뜨면 보통 점화플러그와 코일부터 바꿉니다. 그런데 바꿔도 그대로인 경우가 적지 않습니다. 여러 기통이 동시에 실화한다는 건 공통 원인이 따로 있다는 뜻입니다.

  1. 증상

    엔진 경고등, 공회전 떨림, 가속 불량

  2. 진단

    전 기통 데이터 비교 후 압축 · 연료 · 점화 계통 교차 검증

  3. 작업

    특정된 원인 부위만 수리 (부품 무작정 교체 없음)

  4. 결과

    코드 소거 후 재발 여부까지 확인하고 출고

전 차종 전장 진단 충전 경고등

배터리 경고등 — 발전기부터 갈면 돈 버립니다

충전 경고등이 떴다고 발전기를 먼저 교체하는 경우가 많습니다. 원인은 배터리일 수도, 배선일 수도 있습니다. 전압을 각각 재보면 5분 만에 갈립니다.

  1. 증상

    충전(배터리) 경고등 점등, 시동 불량

  2. 진단

    발전 전압과 배터리 상태를 각각 측정해 원인을 분리

  3. 작업

    실제 원인 부위만 교체 또는 수리

  4. 결과

    충전 전압 정상 확인 후 출고
